# Finance Bot — личный финансовый Telegram-бот

Telegram-бот + Mini App для учёта личных финансов: расходы в тенге, инвестиционный портфель во Freedom Broker в долларах, халяль-финансы (риба, закят, скрининг инвестиций) и еженедельные отчёты с графиками. Репозиторий: dam1r-dev/FinanceBot_V1.

## Зачем этот проект

Сделан под личные боли, а не как универсальный продукт (хотя рассчитан на то, что им будут пользоваться ещё несколько близких людей). Кастдев с самим собой выявил пять проблем, которые бот должен закрывать:

1. Непонятно, куда уходят деньги — нет учёта расходов.
2. Не получается копить/откладывать — нужна дисциплина через цели.
3. Слабая ориентация в халяльных финансах (риба, гарар, закят, халяль-инвестиции).
4. Пробелы в базовых финансовых темах (кредиты, инфляция, инвестиции, налоги).
5. Хочется видеть графики и таблицы, а не только текст в чате.

Полная версия кастдева и обоснование решений — в [docs/SPEC.md](docs/SPEC.md).

## Функциональность

### Учёт расходов

- Ввод трат текстом («кофе 1500», «1500 такси», можно с валютой — «20 usd такси»).
- Ввод по фото чека (сейчас — заглушка с просьбой ввести вручную, см. «Что не доделано» ниже).
- Категории создаются на лету, лимиты по категориям (`/budget`) с недельным окном и автоматическим алертом при превышении.
- Мультивалютность: основная валюта KZT, поддержка USD (для позиций Freedom Broker) с конвертацией по курсу, который кэшируется в БД раз в сутки.

### Цели и дисциплина

- Накопительные цели (`/goal <название> <сумма>`, `/goals` — прогресс по всем).

### Халяль-финансы

- Короткие уроки по теме (`/halal <номер>`): риба, гарар, закят, принципы халяль-скрининга инвестиций.
- Калькулятор закята (`/zakat <сумма>`) — 2.5% с накоплений выше нисаба.
- Rule-based скрининг тикеров портфеля (`/screen <тикер>`) по упрощённой методологии (сектор бизнеса, долг/капитализация, процентный кэш/капитализация, доля харам-выручки) — логика готова, но без реального источника финансовых данных по эмитентам (см. ограничения).

### Отчёты

- `/report` — отчёт по требованию: графики расходов по категориям и тренда за неделю (через QuickChart, без нативных зависимостей — работает и в serverless).
- Еженедельный автоматический отчёт по воскресеньям, 20:00 Asia/Almaty.

### Mini App (дашборд в Telegram)

Открывается кнопкой из бота, показывает то, что неудобно смотреть в чате: интерактивные графики по категориям и динамике трат, таблица последних транзакций, прогресс по целям, портфель с халяль-статусом по каждой позиции.

## Архитектура и стек

Бот работает через webhook, а не long-polling: Telegram сам стучится в эндпоинт, который "спит", когда сообщений нет, и просыпается на входящий запрос. Это позволяет держать бота бесплатно на serverless-платформе (Vercel) без постоянно работающего сервера.

```
packages/
  db/       Общая Prisma-схема и клиент (Postgres, Prisma 7 + driver adapter).
            Единая точка правды для бота и Mini App.
  bot/      Логика бота (grammY): хендлеры команд, парсер трат, халяль-скрининг,
            рендер графиков. Библиотека — используется и в webhook (Vercel),
            и как standalone long-polling процесс (`src/main.ts`, для тех, кто
            предпочитает свой сервер вместо serverless).
  miniapp/  Next.js 16 (App Router). Это то, что реально деплоится на Vercel:
            сам Mini App-дашборд + API-роуты данных + webhook-эндпоинт бота +
            cron-роут для еженедельных отчётов.
docs/
  SPEC.md   Результат кастдева: боли, принятые решения, что вне скоупа MVP.
```

Технологии и почему они:

| Слой | Технология | Почему |
|---|---|---|
| Бот | grammY (TypeScript) | Современный, лучше типизирован под TS, чем Telegraf |
| БД | PostgreSQL + Prisma ORM 7 | Prisma 7 требует явный driver adapter (`@prisma/adapter-pg`) — учтено в `packages/db/src/client.ts` |
| Mini App | Next.js 16 (App Router) + Tailwind + Recharts | Единый стек для дашборда и API-роутов |
| Графики в чат | QuickChart (внешний бесплатный API) | Альтернатива chartjs-node-canvas не годится — тянет нативные биндинги canvas, которые часто ломаются на serverless |
| Хостинг БД | Neon (serverless Postgres, free tier) | Без карты, скейлится в ноль в простое, 100 compute-часов/мес хватает за глаза |
| Хостинг бота/аппа | Vercel (Hobby, free) | Один и тот же деплой обслуживает и Mini App, и webhook бота, и cron |
| Планировщик отчётов | Vercel Cron | Free-план ограничивает cron одним запуском в сутки — роут сам проверяет, воскресенье ли сегодня |

### Модель данных (кратко)

`User` (по `telegramId`) → `Expense` (сумма, валюта, категория, источник: текст/фото), `Budget` (лимит на категорию за период), `Goal` (цель накопления), `Investment` (позиции Freedom Broker + халяль-статус), `ExchangeRate` (кэш курсов), `ReportLog` (история отправленных отчётов). Полная схема — `packages/db/prisma/schema.prisma`.

## Переменные окружения

См. `.env.example` в корне. Ключевые:

- `BOT_TOKEN` — токен от @BotFather.
- `DATABASE_URL` — строка подключения к Postgres (Neon в проде).
- `MINI_APP_URL` — публичный HTTPS-адрес деплоя (домен Vercel).
- `TELEGRAM_WEBHOOK_SECRET`, `CRON_SECRET` — случайные строки для защиты webhook- и cron-эндпоинтов.
- `OCR_PROVIDER`, `OCR_API_KEY` — под будущую интеграцию OCR чеков.
- `FX_API_URL` — источник курсов валют (по умолчанию open.er-api.com, бесплатный, без ключа).

## Локальный запуск

```bash
npm install
npm run prisma:migrate      # накатить схему на локальный/Neon Postgres
npm run bot:dev             # бот в режиме long-polling (для разработки)
npm run miniapp:dev         # Mini App на localhost:3000
```

Для теста Mini App внутри самого Telegram нужен публичный HTTPS-туннель (`ngrok http 3000` или деплой на Vercel) — прописать в `MINI_APP_URL` и в настройках бота у @BotFather.

## Бесплатный деплой 24/7 (прод)

1. **Neon** — создать проект на neon.com, скопировать connection string → `DATABASE_URL`.
2. **Vercel** — импортировать репозиторий, Root Directory = `packages/miniapp`, прописать env vars (см. выше), Deploy.
3. Накатить миграции на прод-базу: `DATABASE_URL="<neon-строка>" npm run prisma:migrate`.
4. Привязать webhook:
   ```bash
   curl -F "url=https://<домен>.vercel.app/api/telegram-webhook" \
        -F "secret_token=<TELEGRAM_WEBHOOK_SECRET>" \
        "https://api.telegram.org/bot<BOT_TOKEN>/setWebhook"
   ```
5. Проверить: `curl "https://api.telegram.org/bot<BOT_TOKEN>/getWebhookInfo"`.

Еженедельный отчёт после этого рассылается сам через Vercel Cron — ничего дополнительно поддерживать не нужно.

Альтернатива для тех, кто предпочитает свой сервер: `packages/bot` можно запускать как обычный long-polling процесс на любом VPS или Oracle Cloud Free Tier (always-free ARM-инстансы) — `npm run build && npm start` в `packages/bot`.

## Что не доделано (осознанно, MVP)

- **OCR фото чеков** — сейчас просит ввести сумму вручную. Интерфейс уже готов под замену (`packages/bot/src/services/ocr.ts`), нужен реальный провайдер (Google Vision / Claude vision) и ключ.
- **Халяль-скрининг** — бизнес-логика (пороги по долгу, кэшу, харам-выручке) реализована и покрывает методологию, но без источника финансовых данных по тикерам (нужен API вроде financialmodelingprep.com или Alpha Vantage).
- **Импорт портфеля Freedom Broker** — позиции добавляются вручную через API, автоматической синхронизации с брокером нет.
