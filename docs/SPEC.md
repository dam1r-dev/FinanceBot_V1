# Финансовый Telegram-бот Дамира — SPEC (v0.1, из кастдева 03.08.2026)

## 1. Кто пользователь
Прежде всего — сам Дамир. Плюс узкий круг (друзья), без публичного запуска на первом этапе.
Архитектура должна быть multi-user с самого начала (User таблица, привязка по telegram_id),
чтобы не переписывать при расширении круга, но UX не проектируется под "массовый продукт".

## 2. Боли, которые бот должен закрывать
1. Не понятно, куда уходят деньги — нет учёта расходов.
2. Не получается копить/откладывать — нужна дисциплина через цели и челленджи.
3. Слабая ориентация в халяльных финансах (риба, гарар, закят, халяль-скрининг инвестиций).
4. Пробелы в базовых финансовых темах (кредиты, инфляция, налоги, инвестиции).
5. Хочется видеть графики и таблицы, а не только текст.

## 3. Валюты
- Основная валюта учёта: **KZT (тенге)**.
- Дополнительно: инвестиционный портфель во **Freedom Broker**, частично в **USD**.
- Нужна мультивалютность: хранить сумму + валюту у каждой транзакции/позиции,
  показывать сводки и в KZT (с конвертацией по курсу), и в исходной валюте.
- Курс валют — тянуть с бесплатного FX API (например exchangerate.host или НацБанк РК), кэшировать раз в день.

## 4. Ввод данных
- Текстом в чат: `кофе 1500` → бот парсит сумму + категорию (эвристика/AI-классификация).
- Фото чека → OCR (Vision API / LLM-vision) → парсинг суммы, даты, мерчанта, предложенной категории,
  пользователь подтверждает/правит перед сохранением.

## 5. Функциональность MVP
- **Трекер расходов/бюджета**: категории, лимиты по категориям, история.
- **Цели/челленджи**: накопительные цели (сумма + срок), прогресс-бар.
- **Халяль-блок**:
  - Серия уроков (риба, гарар, закят, халяль-инвестиции) — короткие сообщения/карточки.
  - Калькулятор закята по текущим накоплениям.
  - Скрининг халяльности бумаг из портфеля Freedom Broker (rule-based: долговая нагрузка,
    доля "харам"-выручки, объём кэша/процентных активов — по методологии AAOIFI/подобной,
    упрощённо на MVP, с explicit TODO на реальный источник фин. данных по эмитентам).
- **AI-коуч в чате**: можно спросить "как у меня дела с бюджетом", "почему я трачу больше", получает
  ответ на основе последних транзакций и целей.
- **Напоминания/отчёты**:
  - Еженедельный отчёт с графиками (расходы по категориям, тренд, прогресс по целям).
  - Алерт сразу при превышении лимита по категории.
  - Графики "по требованию" — команда/кнопка в любой момент.

## 6. Интерфейс
Гибридный подход:
- **Бот (чат)** — основной канал ввода (текст, фото чека), быстрые команды, алерты, AI-коуч диалог.
- **Telegram Mini App (Next.js)** — открывается кнопкой из бота для всего, что лучше смотрится
  визуально: интерактивные графики, таблица транзакций, дашборд целей, портфель с халяль-статусом.

## 7. Технологический стек
- **Bot**: Node.js + TypeScript, grammY (современный, лучше типизирован чем Telegraf для TS-проектов).
- **DB**: PostgreSQL + Prisma ORM 7 (обязательно с `@prisma/adapter-pg`, см. gotchas).
- **Mini App**: Next.js 16 (App Router), Tailwind, графики — Recharts.
- **OCR**: интерфейс-стаб под Vision API (Google Vision / Claude vision) — ключ добавляется пользователем.
- **FX**: внешний бесплатный API курсов валют, кэш в БД.
- **Планировщик**: Vercel Cron (прод) + node-cron fallback в standalone-режиме бота.
- **Монорепо**: npm workspaces, `packages/db` + `packages/bot` + `packages/miniapp`.

## 8. Вне скоупа MVP (roadmap)
- Реальная интеграция с Freedom Broker API (сейчас — ручной ввод позиций).
- Полноценный AAOIFI-скрининг с живыми финансовыми данными эмитентов.
- Реальный OCR-провайдер для фото чеков (интерфейс готов, ключ не подключён).
- Мультиязычность интерфейса (RU и так основной язык Дамира).
- Публичный запуск для широкой аудитории, монетизация.
